# LUNARA asset generation plan

## Design source

The supplied master project brief defines LUNARA’s editorial direction. The palette combines `#E88CB3`, `#F4C4D8`, `#FFF9FB`, `#FFFFFF`, `#29232A`, `#91858E`, `#BBA5D8` and `#82546F`. The artwork uses soft directional light, translucent material, fine matte texture, restrained botanicals and generous clear space. The four cycle illustrations use distinct botanical forms. Pair each with its visible phase label in the product.

The [Stitch project](https://stitch.google.com/projects/4050240494225232368) was reviewed in the signed-in browser. Its Design System board uses Newsreader for headings and Plus Jakarta Sans for body text and labels. Its Splash / Welcome, Home Dashboard, Cycle Tracker and Insights canvases establish a mobile layout with a full-bleed welcome portrait, repeated compact emblem, an ivory shell and rose/lavender accents. The original brand artwork uses a distinct crescent and petal mark.

No pre-existing RITMA directory or product source was present at the requested destination. The illustration assignments for onboarding, wellness and empty states follow the master brief. The phase dial, charts and data icons shown in Stitch are UI elements for the product phase.

## Production sequence

1. Inventory 30 assets across brand, editorial, backgrounds, onboarding, cycle, wellness and empty states.
2. Generate each photograph and illustration from its own prompt. Create one scalable crescent-and-petal brand symbol and derive the logo lockups and app icon from it.
3. Compare images as sets, then inspect individual subjects and crop margins. Validate all deliverable files, including transparency for empty states and logo SVGs.
4. Export lean WebP, SVG and PNG files and publish a catalog with usage, sizes, focal points and alt text.
5. Review the contact sheet and mobile crop samples before approving product screen usage.

## Handoff

- `ASSET_MANIFEST.md` inventories all assets and their current status.
- `ASSET_GENERATION_PROMPTS.md` records the generation and vector construction briefs.
- `ASSET_QA_REPORT.md` records visual and technical checks.
- `ASSET_REVIEW.html` opens the offline gallery with links to each asset file.
- `../public/assets/catalog.json` provides root-relative web paths for future consumers.

The next milestone is stakeholder approval of the asset library and validation of placements during product integration. Phase 04 starts after the review.

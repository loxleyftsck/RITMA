## Usage

- Import the entries in `public/assets/catalog.json` using their root-relative paths for the app. The offline gallery resolves equivalent relative paths.
- Retain the declared image dimensions and focal point when adopting an image. Display the hero as landscape or crop around its focal point for narrow cards.
- Use empty alt text for decorative backgrounds and empty-state images alongside visible status copy. Use empty alt text for a repeated logo next to the brand name. Give any linked logo an accessible name based on its destination.
- The illustrations, avatars and motion directories are reserved by the brief. All Phase 03 illustration files have a category-specific folder. No generic avatars or animations were specified.
